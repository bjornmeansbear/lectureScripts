# SampleSlides

Three NodeBox sketches from November 2020 that set slide titles in a range of typefaces, for the climate design talk and Signs Signaling Sustainability.

- `020201123-ClimateDesignTalkSlides.ndbx`
- `ClimateDesignerSlideText.ndbx`
- `ClimateDesignerSlideText2.ndbx`

The SVGs they render (1,582 files, about 630 MB) are not in git. They're in `Dropbox/2 Teaching/lectureScripts-files/SampleSlides/`, in the same folders they had here: `0202011222331-v1/`, `0202011232134-V2-SlideTitles/export/`, the `CC-SSS-*` set, and the named font tests (`SignsSignallingSustainability-<font>.svg`, `SoYouWantToBeACD-<font>.svg`). Open a sketch in NodeBox to render them again.
