## How to use this

- Starting a new workshop or lecture write-up: skim this file first. If your topic touches something already listed, cite/cross-reference rather than re-deriving.
- Found a new overlap while writing? Add it here in the same pass — don't let it live only inside one file's "Bibliography" or "Notes to self" section, or the next workshop won't find it.
- This file tracks *ideas*, not files — never duplicate actual paragraphs of content across folders. One copy, cross-referenced from here.
