The plan/concept for the class is as follows:
— Investigate and use available open source design tools — gimp, inkscape, blender, scribus, drawbot, fontforge, etc. This also includes open/libre fonts, as well as OSs (different flavors of linux?). My main constraint is that for anything made in/for the class we use open source tools to do it — this means no Creative Suite! Through our investigations we'll then analyze the pros/cons of these tools and how a designer might start using them/participating in their communities/etc.

— Explore open source ideals.

— Interviews/Discussions/Lectures w/ open source dignitaries

— The main project: do a bunch of things and then turn it into a book that we make w/ the tools and ideas we've uncovered...
