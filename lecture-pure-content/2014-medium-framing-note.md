# The Medium framing note

From ["From InDesign to Pure Content"](https://medium.com/@bjornmeansbear/from-indesign-to-pure-content-ac9db7f03fcd) on Medium, which notes it was *"originally published at https://www.bjornpaedia.com."*

The essay body is already in bjornpaedia as `From Indesign to Pure Content.tid` (472 words, complete). **Only this framing note is missing there** — and it carries the dating and context that nothing else in the archive has. Recovered 2026-08-27.

> XML version of content to be fed to Indesign, Structure already in the XML automatically can display paragraph styling named with same name as tags. woohoo.
>
> The following essay is from **a series of writings I turned into a lecture in 2014**. **From 2011–2014** my work colleagues and I explored a bunch of custom cobbled together tools and ideas we called "CAPE: Create Anywhere Publish Everywhere" — this was about how we could take content developed in a variety of places and cut it up and feed it to all the other places we might need it… Now the modern web works a lot like this, but in 2011/2012 we thought we were geniuses… Anyway, I was trying to find ways to send things direct to indesign for a more controlled printing solution than HTML/CSS print styling could get us… #purecontent

## What this adds

**There was a 2014 lecture, before the 2015 paper.** "A series of writings I turned into a lecture in 2014." Venue unknown. The Web Archives 2015 paper may be a second outing of the same material, or a development of it. Two deliveries, not one.

**The print mechanism, named.** XML fed to InDesign, where structure already in the XML maps automatically onto paragraph styles that share the tag names. That is the concrete answer to "how did you generate print from the same source," which the case study claims and never explains. `InDesign likes XML, most web things like JSON` is the same point in the essay body.

**⚠ Date conflict, unresolved.** This note says CAPE ran **2011–2014**. Kristian said **≈2012–2023** when asked directly on 2026-08-27, and that range is currently published in the case study dek on `a.wjerk.shop`. Both can be true — the tool-building may be 2011–14 and the practice continued far longer — but the page currently asserts one of them. **Needs his call before the dek is trusted.**

**Medium is a surface nobody had recorded**, and it is downstream of bjornpaedia rather than upstream: "originally published at bjornpaedia.com." Which is the whole thesis operating — one source, several renderings.
