# Intro to Sustainable Packaging (2019)

A talk from February and March 2019: what a package is for (protect, inform, sell), the three layers of packaging, packaging as a boundary, and whether a package needs to exist at all. Built in Scribus, with Flickr Commons images and libre fonts.

## Class projects that go with this talk

From Package Design (GD365), first taught at MICA in Spring 2014. Rescued from the old teaching.ookb.co site on 2026-11-19. CC BY-SA 4.0, like the rest of this repo.

- [Best/Worst](project-best-worst.md): intro assignment, one week
- [Worst Re-Design](project-worst-redesign.md): Project 1, the research-heavy one
- [Packaging the Immaterial](project-packaging-the-immaterial.md): Project 2 (requirements were never written; see the notes)
- [The Best Package Ever](project-best-package-ever.md): the final project
- [Package Cooker](exercise-package-cooker.md): in-class brainstorming game, with the full lists
- [The 2014 course outline](gd365-package-design-2014.md): schedule, demos, materials, readings

## The talk itself

Nothing from the talk is copied in here yet. The pieces are:

- **Script and deck source.** github.com/bjornmeansbear/sustainable-packaging: `README.md` (the script), the Scribus file (65 slides, 1920×1080), and the final PDFs.
- **Notes, cut into pages.** Tiddlers in `sentence-a-day`, starting from `Intro to Sustainable Packaging` and the hub page `Packaging`.
- **Images.** The Are.na `packaging` channel (`packaging-3dfpkpullxe`). The repo's `links/` folder holds the Flickr images the deck uses, and `Examples-nonlibre/` holds copyrighted examples that shouldn't stay public.
