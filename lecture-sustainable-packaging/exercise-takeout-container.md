# Chinese Takeout Container

Mini project, Package Design (GD365) · first run at MICA, Spring 2014 · goes with [Intro to Sustainable Packaging](README.md) · CC BY-SA 4.0

## The brief

Build a Chinese takeout container from the supplied dieline. Then rethink what it could be used for. Same structure, new contents, new life. Design the exterior to make it clear what the new use is.

## Notes for reuse

- The found dieline is the point: students start from an existing, proven structure instead of inventing one. It's the same question the final project asks, “Can a pre-existing structure be re-engineered?” See [The Best Package Ever](project-best-package-ever.md).
