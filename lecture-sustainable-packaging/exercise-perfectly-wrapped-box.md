# A Perfectly Wrapped Box

Mini project, Package Design (GD365) · first run at MICA, Spring 2014 · goes with [Intro to Sustainable Packaging](README.md) · CC BY-SA 4.0

## The brief

Make a box. Then wrap it perfectly in a printed outer sheet, so the mockup reads like a real, manufactured box.

The point is craft. A comp on a desk has to stand in for something that will come off a production line, so the edges, corners and seams have to look like a machine did them.
